## 🎆 Sobre o Projeto

O **New Years Eve** é um projeto minimalista e acolhedor criado para acompanhar os dias, horas, minutos e segundos restantes até a chegada do próximo Ano Novo.

Mantendo a essência e a fotografia original de inverno capturada por Gabriel, o projeto foi refinado com elementos modernos de design e interatividade.

---

## ✨ Principais Melhorias Implementadas

- ⏳ **Cálculo Automático do Próximo Ano:** Fim das datas fixas que expiravam. O algoritmo agora calcula dinamicamente o próximo 1º de Janeiro de forma perpétua.
- ❄️ **Efeito de Neve em Canvas:** Partículas sutis e fluidas caindo suavemente pela tela sem comprometer a performance, com botão para ligar/desligar.
- 🪟 **Cards em Glassmorphism:** Números do contador destacados em blocos translúcidos com efeito de vidro fosco (*backdrop-filter: blur*), garantindo legibilidade perfeita sobre qualquer foto.
- 📊 **Barra de Progresso do Ano:** Indicador visual que mostra a porcentagem exata já percorrida do ano atual.
- 🖼️ **Alternador de Cenário:** Permite alternar facilmente entre as fotos de neve capturadas por Gabriel.
- 💬 **Frases Inspiradoras de Ano Novo:** Mensagens reflexivas e motivacionais que se alternam suavemente na tela.
- 📱 **Responsividade Total:** Grade adaptativa (2x2 em celulares pequenos e 4 colunas em tablets e desktops) com tipografia fluida via `clamp()`.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Marcação semântica e acessível com tags semânticas.
- **CSS3:** Flexbox, CSS Grid, Glassmorphism, animações e gradientes.
- **JavaScript Puro:** Cálculo temporal preciso, manipulação de DOM e animação de partículas com Canvas 2D.
- **Google Fonts:** Tipografia com a família *Poppins*.

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/igorgoms/New-Years-Eve.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd New-Years-Eve
   ```

3. Abra o arquivo `index.html` diretamente em seu navegador.
